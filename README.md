 # ❤️ Heart Disease Prediction System

## About the Project
A machine learning web application that predicts the possibility of heart disease using patient health parameters.

## Features
- User login and registration
- Heart disease prediction
- Machine learning model integration
- Prediction results
- Prediction history

## Technologies Used
- Python
- Flask
- Pandas
- Scikit-learn
- XGBoost
- HTML and CSS
- SQLite
- Jupyter Notebook

## Project Files
- `app.py` — Main Flask application
- `dataset.csv` — Dataset
- `heart.ipynb` — Machine learning notebook
- `predict.html` — Prediction page
- `result.html` — Results page
- `style.css` — Website styling
- `xgboost_app_model.sav` — Saved model

## How to Run
1. Install Python.
2. Install the required dependencies.
3. Run `python app.py`.
4. Open the local URL shown in the terminal.

## Disclaimer
This project is for educational purposes only. It does not provide a medical diagnosis.
